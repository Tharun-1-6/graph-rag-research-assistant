--------------------------------------------------------------------------------
2. MODELS
--------------------------------------------------------------------------------
* Embeddings Model:
  - Name/Identifier: sentence-transformers/all-MiniLM-L6-v2
  - Source/Registry: Hugging Face (Hugging Face Hub)
  - Type: Sentence-Transformers Embedding Model (Dense Vector Embeddings)
  - Description: Maps sentences & paragraphs to a 384-dimensional dense vector 
    space. It is optimized for semantic search and retrieval tasks.
  - Used in:
    * Ingestion: generating vector representations for text chunks (ingest.py)
    * Retrieval: generating vector representations for user queries (retrieve.py)

--------------------------------------------------------------------------------
3. TOOLS & LIBRARIES
--------------------------------------------------------------------------------
* Vector Database / Indexing:
  - Name: FAISS (Facebook AI Similarity Search)
  - Python Package: faiss-cpu (v1.14.3)
  - Wrapper: FAISS class from langchain_community.vectorstores
  - Type: Vector Database / Similarity Search Index
  - Source: Meta (Facebook) AI Research
  - Description: Used to index document embeddings and perform fast similarity 
    searches using cosine/Euclidean distance metrics.

* Text Chunking/Splitting:
  - Name: RecursiveCharacterTextSplitter
  - Python Package: langchain-text-splitters (v1.1.2) or langchain (v1.3.11)
  - Type: Document Preprocessing & Chunking Tool
  - Source: LangChain
  - Description: Splits loaded text documents into smaller chunks of 1000 characters 
    with a 100-character overlap. Recursively splits on spaces, newlines, etc. to 
    keep semantically related text together.

* PDF Document Loading:
  - Name: PyPDFLoader
  - Python Package: langchain-community (v0.4.2) / pypdf (v6.14.2)
  - Type: Data Ingestion / Document Loader
  - Source: LangChain Community (wrapper around pypdf library)
  - Description: Extracts text from PDF files in the data directory and loads 
    them as Document objects with associated page metadata.

* Text Document Loading:
  - Name: TextLoader
  - Python Package: langchain-community (v0.4.2)
  - Type: Data Ingestion / Document Loader
  - Source: LangChain Community
  - Description: Loads raw text (.txt) files in UTF-8 encoding as LangChain 
    Document objects for processing.
